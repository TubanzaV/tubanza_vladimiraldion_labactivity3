## System Design
The program is built using two main classes:
1. `HardwareItem`: Handles individual component attributes (ID, name, category, quantity, price) e.g. [CPU-01, Ryzen 9 3950X, Processor, 15, 299] and item-specific behaviors like restocking and dispensing.
2. `InventorySystem`: Acts as the inventory manager. It stores `HardwareItem` objects in a dictionary, routes transactions, and generates formatted system reports.
